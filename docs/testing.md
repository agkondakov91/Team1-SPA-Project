Документация по тестированию веб-приложения

Основные файлы для проверки
- index.html
- script.js
- style.css

Критерии тестирования
- Кликабельность кнопок
- Работоспособность функционала
- Визуальное оформление на разных устройствах
- Сравнение с макетом

Тест-кейсы

1. Статья Utility
   - Шаги для воспроизведения: Проверить наличие статьи
   - Ожидаемый результат: Статья присутствует
   - Фактический результат: Полное отсутствие
   - Серьезность: Critical
   - Приоритет: High

2. Статья CMS Pages
   - Шаги для воспроизведения: Проверить наличие статей
   - Ожидаемый результат: Существуют статьи BLOG 1-3 и другие
   - Фактический результат: Только одна статья WORKS
   - Серьезность: Critical
   - Приоритет: High

3. Последняя страница (POWERED BY, CREATED BY)
   - Шаги для воспроизведения: Проверить наличие страницы
   - Ожидаемый результат: Страница присутствует
   - Фактический результат: Полное отсутствие
   - Серьезность: Major
   - Приоритет: Medium

4. Подключение файлов
   - Шаги для воспроизведения: Проверить наличие подключений
   - Ожидаемый результат: api.js и App.js подключены
   - Фактический результат: Не подключены
   - Серьезность: Minor
   - Приоритет: Low

Адаптивность веб-приложения

Цели тестирования
- Проверить корректное отображение на разных экранах
- Убедиться в удобстве взаимодействия на мобильных устройствах
- Оценить изменение дизайна при изменении размера окна

Критерии адаптивности
- Правильная загрузка элементов интерфейса на экранах различных размеров
- Смена расположения элементов (например, кнопки и меню) на мобильной версии
- Читаемость текста и кнопок на меньших экранах

Тест-кейсы по адаптивности

1. Отображение на мобильных устройствах
   - Шаги: Открыть приложение на телефоне
   - Ожидаемый результат: Элементы располагаются корректно, все функциональности доступны
   - Фактический результат: Кнопки не помещаются на экран
   - Серьезность: Major
   - Приоритет: High

2. Изменение размера окна
   - Шаги: Сжать окно браузера
   - Ожидаемый результат: Элементы перестраиваются без потери функционала
   - Фактический результат: Элементы наложены друг на друга
   - Серьезность: Critical
   - Приоритет: High

3. Читаемость текста
   - Шаги: Проверить текст на всех устройствах
   - Ожидаемый результат: Текст легко читаем
   - Фактический результат: Шрифт мелкий или не контрастный
   - Серьезность: Minor
   - Приоритет: Medium
