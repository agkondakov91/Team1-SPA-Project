## Общая информация
Данный CSS код предназначен для стилизации веб-страницы, связанным с UI Kit "Zero Design". Он устанавливает основные стили для элементов, включая шрифты, отступы, цвета и поведение интерактивных элементов.

## Основные стили

### Переменные
- `--font-family-main`: Определяет основной шрифт страницы, используется для текстовых элементов.

### Глобальные стили
- Устанавливаются значения `margin` и `padding` равными 0 для всех элементов.
- Определяется плавный скролл для страницы.

### Стили `body` и `header`
- `body`: Применяется основной шрифт и отступы по бокам.
- `header`: Используется flexbox для выравнивания элементов и задаются отступы.

### Стили для навигации
- `.nav-h`: Убирается подчеркивание и списковый стиль, устанавливается цвет ссылок и эффекты наведения.
- `#burger-menu`: Ответственно за стили для мобильного меню.

### Стили кнопок
- `#buy-now`, `#burger-btn`: Определены стили для кнопок с эффектами при наведении и нажатии.

### Стили заголовков и текстов
- Заголовки (H1, H2, H3 и т.д.) имеют разные размеры и цвета.
- Параграфы имеют определенный шрифт и цвет.

### Стили для карточек и информационных блоков
- `.card`: Задается отступы и стили для карточек.
- `#info1`, `#info2`: Используются для стилизации информационных секций.

### Макеты
- `.wrap`: Определяет grid-структуру для элементного расположения.

## Заключение
CSS стили в этом коде обеспечивают адаптивный дизайн и привлекательный интерфейс для пользователей, способствуя легкости навигации и взаимодействия с контентом.
