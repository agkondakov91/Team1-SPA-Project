## Общая информация
Данный HTML документ представляет собой страницу о дизайнерском UI Kit под названием "Zero Design". Он включает в себя элементы навигации, описания, а также разделы с информацией о продукте.

## Структура документа

### `head`
Содержит мета-информацию и стили:
- `meta` теги: описывают кодировку, масштаб и ссылку на стили.
- `link`: подключение файлов стилей.
- `title`: заголовок страницы, отображаемый в браузере.

### `body`
Основное содержимое страницы описано в данной секции. 

#### Раздел `burger-menu`
Содержит мобильное меню с логотипом и навигацией:
- Изображение логотипа.
- Список навигационных ссылок.
- Кнопка для покупки.

#### Раздел `header`
Основная шапка сайта с логотипом и навигационными ссылками:
- Логотип с отступами.
- Список навигации с якорными ссылками.
- Кнопка "Buy Now" и значки поиска и магазина.

#### Раздел `info1`
Предоставляет информацию о продукте:
- Заголовки (H1, H2, H3) и абзац с описанием.
- Карточки с изображениями и текстом, демонстрирующие основные функции UI Kit.

#### Раздел `info2`
Содержит изображение и информацию о структуре продукта:
- Заголовок и абзац, описывающий содержимое пакета.
- Нумерованный список статических страниц и страниц CMS.

## Используемые ресурсы
В коде используются ссылки на изображения и CSS файлы, которые должны быть доступны на сервере.

## Контент
Текст контента следует адаптировать для конечного пользователя, отображая особенности продукта максимально привлекательно.
